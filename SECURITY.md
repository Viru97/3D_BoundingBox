# Security Policy

## Supported Versions

Security fixes are applied to the latest revision of the default branch.

## Reporting a Vulnerability

Please report vulnerabilities privately through the repository owner's GitHub contact channel. Do not include sensitive datasets, model weights, credentials, or customer information in a public issue.

This repository processes local files supplied by the operator. Treat datasets, checkpoints, and ONNX models as untrusted inputs unless they come from a controlled source.
